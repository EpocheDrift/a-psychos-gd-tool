# Security policy

English · [简体中文](SECURITY.zh-CN.md)

## Supported code

This project is still pre-release. Security fixes target the latest `main`
branch; older commits and untagged snapshots do not receive separate support.
There is currently no guaranteed response-time SLA.

## Report a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/EpocheDrift/a-psychos-gd-tool/security/advisories/new).
Do not open a public issue for a vulnerability before a fix or coordinated
disclosure is ready.

Include the affected commit, reproduction steps, impact, and any suggested
mitigation. Do not include credentials, private project files, model cache
contents, or other people's data.

The current reviewed dependency exceptions and their expiry are recorded in
[the dependency security baseline](docs/dependency-security.md).
