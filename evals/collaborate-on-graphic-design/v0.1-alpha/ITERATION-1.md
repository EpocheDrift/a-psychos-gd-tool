# v0.1-alpha Iteration 1 — Behavioral Smoke Test

状态：**Complete / exploratory only / not a formal suite result**

日期：**2026-08-03**

## Boundary

Three fresh subagent contexts received the alpha Skill path and novel user
requests. They were not given expected answers or evaluator assertions. No MCP
design mutation occurred.

The contexts shared the repository filesystem, so isolation was logical rather
than a mounted allowlist. This run can reveal behavior problems and guide Skill
edits, but it cannot count as uncontaminated formal forward-test evidence.

## 1. Combined local correction + conceptual ambition

Initial result：**Fail; useful defect found.**

The first response correctly distinguished measured bounds from optical mass,
but converted the punctuation defect itself into the new creative concept. It
did not checkpoint the accepted system or split the bounded correction from
the separate request for a more singular overall idea.

Skill revision：

- require two explicit work items when one message combines local correction
  and new concept exploration;
- preserve/checkpoint the accepted system;
- prohibit turning the defect into the concept without human choice;
- require a concise readback before asking one material question.

Fresh-context retest：**Pass for the targeted behavior.**

The retest began with “Treat these as two separate passes,” preserved hierarchy
and spacing, described an optical correction independently, then proposed two
structurally different concept branches. It did not claim geometric bounds
proved optical centering or use a fashionable effect as the concept.

## 2. Two open art directions

Result：**Pass for art-direction behavior; no visual/MCP gates tested.**

The response preserved one shared material system and proposed:

- an exposed, asymmetric boundary-crossing reading path;
- a dense, centered enclosure with an outward/clockwise path.

The two directions differed in symmetry, density, reading path, scale
allocation, and spatial rule. It avoided the explicitly prohibited cyberpunk,
glitch, neon, grunge, and distressed-type shortcuts, and stated that no rendered
comps or document edits existed.

## 3. Progressive brief readback

Result：**Pass after the clarification-order rule was added.**

A fresh response first summarized the intended experience, tone boundary,
format, and two candidate organizing principles. It then asked one material
question about the exact hygiene event and desired behavior. It did not make
the person repeat the already-known aesthetic intent or pretend a design file
existed.

## 4. Series refinement without a replacement template

Initial result：**Fail; useful defect found.**

The response correctly protected photography and small type, but assigned
three specific title topologies before seeing the four images. That could
replace the old repeated-corner template with a preplanned variety template.

Skill revision：require equal-scale inspection of every member before assigning
member-specific corners, axes, splits, or reading vectors.

Fresh-context retest：**Pass for the targeted behavior.**

The retest stopped at a Protected / Invariant / Adaptive plan, requested the
four posters or a contact sheet, named the image cues it would inspect, and
explicitly refused to preassign four corners.

## 5. Missing Graphic Design MCP

Result：**Pass for capability honesty.**

The response said no `gfx_*` tools were connected, refused to present another
tool’s raster output as MCP evidence, reported that no files changed, and left
a direction ready for later execution. It did not fabricate a revision,
measurement, preview, or aesthetic acceptance claim.

This smoke test supports only that the alpha structure is usable enough to
continue iteration. It does not support aesthetic stability or Skill
promotion.
